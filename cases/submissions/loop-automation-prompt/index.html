循环自动化提示词：从一次失败到连续运行的 Agent 工作流 ​

本文由一段真实对话整理而来，经心虫（HeartFlow）判别器逐条监督后成文。适合正在搭建"让 Agent 自己跑起来"工作流的团队做内部培训。

场景描述 ​

很多人第一次尝试"自动化"时，会问一个问题：

"我写一个提示词，让 Agent 每天自动跑任务，是不是就循环自动化了？"

答案是否定的。循环自动化不是一次写成的提示词，而是一个需要部署、试错、调参、最终稳定运行的工作流。这段心得来自一次真实的对话复盘：发起人想把一段讨论整理成培训材料，过程中逐步暴露了循环自动化的完整方法论。

核心结论：循环自动化的五步闭环 ​

循环自动化提示词的本质，是一个自我延续的任务链：

text
部署并手动运行 → 运行正常 → 设置定时任务 → 定时任务输出下一个任务计划 → 最后一步设定下一个定时任务 → 循环

五个要点：

  1. 先部署、手动运行正常，再谈自动化。基础信息都没有，谈不上循环——自动化是建立在一次成功运行之上的。
  2. 定时任务不是终点，而是接力棒。每个定时任务的最后一步，必须包含"设定下一个定时任务"的指令，否则链条断裂。
  3. 失败是常态，调整是关键。最开始基本 1-2 次就会失败，要继续调整。能连续正常运行 3 次，基本可以判定这个提示词成功了。
  4. 从 500 字开始，逐步增加到 1000 字。超过 500 字、任务拆分 10 行以上是起步线；"啥时候把这个项目的提示词增加到 1000 字，说明项目离成功不远了"。
  5. 永远没有一句话就能用的提示词。任何提示词都要经过"运行→失败→调整→再运行"的迭代。

详细程度与成功率的关系（心虫补全边界） ​

对话中有一句反问："提示词越多，成功率越高是吗？"

心虫判别后补充的边界：详尽程度与成功率正相关，但有上限。详细提示词（500-1000 字、10 行以上任务拆解）确实显著提升成功率，因为：

  • 明确了任务边界，Agent 不需要猜测意图；
  • 拆解成子任务后，每个环节可独立验证；
  • 写了验收标准，Agent 知道"什么算完成"。

但冗余指令会稀释注意力——与任务无关的细节、重复的约束、互相矛盾的优先级，反而降低成功率。正确做法是：每一条指令都要能回答"它帮助 Agent 更准了吗"，答不出就删掉。

任务性质决定思维模型：注意力权重的调整 ​

对话中的关键洞见：

"看起来像根据任务性质，然后通过对应任务的思维模型对模型的注意力权重调整，然后再让 agent 去执行。"

这句话拆开是三件事：

层次含义示例
任务性质判断任务属于哪一类信息收集 / 数据分析 / 内容生成 / 流程执行
思维模型为该类任务选择合适的思考框架分析类用 SWOT、决策类用决策矩阵、创作类用结构化大纲
注意力权重让模型把"注意力"集中到关键环节分析任务强调"先列下行风险"、生成任务强调"先列结构再填充"

心虫的定位正是这个"判定器"——它是 AGI 五层架构的第一层（辨别层），不生成、不推理，只判别已有的东西对不对。在循环自动化里，心虫做的是：

  • 输入侧：判别任务类型是否匹配所选思维模型；
  • 执行侧：监督每个环节的产出是否达标（有无过度自信、有无矛盾、有无模糊）；
  • 输出侧：门禁拦截——检测到仇恨、操控、虚假声明、无依据断言时，直接 block/rewrite/verify，不让错误内容流向下游。

一句话：任务性质决定思维模型，思维模型决定注意力分配，心虫监督整个过程。

更新日志不是形式：和技能、知识库联动 ​

对话中反思：

"我只是强制完成更新日志，确实应该和技能、知识库联系起来。"

这是个重要教训。强制完成更新日志 ≠ 自动化闭环。更新日志的价值在于：

  1. 记录这次运行改了什么（对比上一次）；
  2. 沉淀成功/失败模式到技能库（下次同类任务直接调用）；
  3. 把经验蒸馏进知识库（让 Agent 的上下文越来越准）。

循环自动化的正确姿势是：每次运行结束，Agent 应该更新日志 + 把新学到的模式写入技能/知识库，这样下一次运行是基于更丰富的上下文，而不是从零开始。

关于比喻：任何比喻都会错位 ​

对话中有一个生动的比喻：

"砍树是任务，而砍树的斧子是工具，挥动斧头砍树是 skills。而不断挥舞斧子的手臂肌肉就是力量。肌肉力量通过不断挥舞斧头从而不断强化。而为什么使用斧子砍树而不是用手就是每个人看东西的角度不一样所采取的策略也不样。"

但紧接着是一句更重要的自我纠正：

"不用比喻，任何比喻都会错位。"

心虫监督后的处理：比喻可以帮助初学者建立直觉，但不能替代对概念本身的精确定义。培训材料里，比喻只作为引导出现一次，随后立即给出准确术语：

比喻准确术语
砍树任务（Task）——要达成的目标
斧子工具（Tool）——完成任务的手段
挥动斧头技能（Skill）——调用工具完成动作的流程
手臂肌肉能力（Capability）——通过反复执行不断强化的系统能力
为什么用斧子不用手策略（Strategy）——不同视角下对同一任务的不同路径选择

心虫监督的价值：它不会因为"这段话写得漂亮"就放行——它逐条检查证据充分性、矛盾、模糊和过度自信。这正是循环自动化里最需要的"判别者"：AI 能产生无限，但需要有人说不。

验收标准 ​

  1. 读者能复述循环自动化的五步闭环（部署→运行→定时→计划→再定时）。
  2. 读者知道"连续运行 3 次"是提示词成功的基本判据。
  3. 读者理解"任务性质→思维模型→注意力权重→Agent 执行"的链路。
  4. 读者能把更新日志和技能/知识库联动，而不是流于形式。
  5. 读者理解比喻的局限，能切换到准确术语。
